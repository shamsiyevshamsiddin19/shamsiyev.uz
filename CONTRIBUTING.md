# Hissa qo'shish yo'riqnomasi (Contributing Guide)

Loyiha ochiq va barcha foydali takliflar, tuzatishlar qabul qilinadi!

## Qoidalar
1. Alohida tarmoq oching: `git checkout -b feature/nomi`
2. Toza kod va arxitektura tamoyillariga rioya qiling.
3. Commit xabarlarini Conventional Commits formatida yozing (`feat:`, `fix:`, `docs:`, `refactor:`).
4. Pull Request yuboring va o'zgarishlar mazmunini qisqacha bayon qiling.
