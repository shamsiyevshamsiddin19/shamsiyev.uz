# Xavfsizlik Siyosati (Security Policy)

## Qo'llab-quvvatlanadigan versiyalar
Ushbu loyihaning so'nggi barqaror versiyasi xavfsizlik yangilanishlari bilan ta'minlanadi.

## Zaifliklar haqida xabar berish
Agar biror xavfsizlik zaifligini aniqlasangiz, uni ochiq issue qilmasdan, rasmiy muallifga xabar qiling.
